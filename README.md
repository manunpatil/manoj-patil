Stock Market Data Analytics and Price Prediction Using Machine Learning

Project Overview:
This project focuses on analyzing stock market datasets using Data Analytics and Machine Learning techniques. The project includes data preprocessing, exploratory data analysis (EDA), feature engineering, PCA, feature selection, and stock price prediction using Linear Regression.

Features:
- Data Cleaning
- Missing Value Handling
- Duplicate Removal
- Date Conversion
- Exploratory Data Analysis
- Correlation Analysis
- Heatmap Visualization
- Outlier Detection
- Feature Engineering
- Standardization & Normalization
- Label Encoding & One Hot Encoding
- Principal Component Analysis (PCA)
- Feature Selection
- Machine Learning Model Building
- Linear Regression Prediction
- Model Evaluation

Technologies Used:
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

Dataset Description:
The dataset contains:
- Date
- Open Price
- High Price
- Low Price
- Close Price
- Adjusted Close Price
- Volume

Project Workflow:
1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis
4. Outlier Detection
5. Feature Engineering
6. Data Transformation
7. PCA & Feature Selection
8. Machine Learning
9. Model Evaluation

Machine Learning Model:
Linear Regression model used for stock closing price prediction.

Evaluation Metrics:
- R² Score
- MAE
- MSE

Key Insights:
- Strong correlations exist between Open, High, Low, and Close prices.
- Feature engineering improved predictive capability.
- PCA reduced dimensionality while preserving important information.
- Linear Regression successfully predicted stock prices.

Conclusion:
This project demonstrates how Data Analytics and Machine Learning techniques can be used effectively for stock market analysis and prediction.
